# Zellij Plugins

Plugin `.wasm` files are not tracked in git. Install them manually:

## zjstatus

Status bar plugin used in `layouts/work.kdl`.

```sh
curl -fsSL https://github.com/dj95/zjstatus/releases/latest/download/zjstatus.wasm -o ~/.config/zellij/plugins/zjstatus.wasm
```

https://github.com/dj95/zjstatus

## zellij_forgot

Keybinding cheatsheet plugin bound to `Ctrl+b` > `?` in `config.kdl`.

```sh
curl -fsSL https://github.com/karimould/zellij-forgot/releases/latest/download/zellij_forgot.wasm -o ~/.config/zellij/plugins/zellij_forgot.wasm
```

https://github.com/karimould/zellij-forgot
